# 宣发方案：把「楚门的2.0世界」发出去

> 定位：不追热点、不烧钱。靠"点开就能玩 + 写了真会改"这两件事，在熟人圈和小红书里滚起来。
> 成本：0 元。工具只需要手机录屏、微信、小红书、剪映。

## 0. 对外只说一句话

**「不用下载、不用注册，点开就是一个会跟着你想法长大的 3D 小森林。」**

这句话是全部素材的地基。所有文案都往它上面靠，别写成"基于 WebGL 的开放共创平台"——没人点。

## 1. 卖点排序（为什么陌生人愿意点开）

| 顺序 | 卖点 | 一句话怎么说 |
|---|---|---|
| 1 | 零门槛 | 微信里点开就玩，不用装、不用登 |
| 2 | 手机竖屏 | 一只手握得住，躺着也能玩 |
| 3 | 有声音 | 雨声、风声、鸟叫、篝火噼啪，全是实时合成的 |
| 4 | 你说的能改 | 留言写"想加水车"，下次更新真有 |
| 5 | 轻 | 不到 1MB，弱网能开，还有低画质开关 |

**别拿"AI 做的"当卖点。** 想讲就放在故事里（"我一个人用零散时间做的"），不要当标题。

## 2. 人群与平台（按投放先后）

1. **微信朋友圈 + 3 个熟人小群** —— 冷启动，先拿 50 个真实打开
2. **小红书** —— 治愈/氛围图人群，9:16 原生适配，最容易出量
3. **视频号 / 抖音** —— 15 秒竖屏动图最直观
4. **即刻 / V2EX / 掘金** —— 技术侧，讲"0 音频文件、600KB"
5. **班级群 / 家长群** —— "孩子能提想法，看着自己的建议上线"

## 3. 三条内容主线（配比 6 : 3 : 1）

**主线一 · 治愈（60%）**
黄昏的光、下雨的屋檐、萤火虫、雾气里的木屋。
文案基调：不说功能，只说感觉。"今天下雨，我把它调成了雨天，听着雨声坐了十分钟。"

**主线二 · 共创（30%）**
把"有人留言 → 我改了 → 上线"做成连续剧。
每期一条：「上周有人说夜里太黑，这周加了萤火虫和路灯，你去看。」

**主线三 · 技术（10%）**
只发技术社区。关键词：无贴图、程序化音频、600KB、离线单文件、GitHub Pages。

## 5. 七天节奏（每天不超过 40 分钟）

| 天 | 动作 | 目的 |
|---|---|---|
| D1 | 朋友圈 1 条 + 3 个熟人小群 | 拿到第一批真实反馈 |
| D2 | 小红书第 1 篇（治愈角度） | 试水封面与标题 |
| D3 | 视频号发 15s 雨天视频 | 动态展示最有说服力 |
| D4 | 小红书第 2、3 篇（共创 / 手机竖屏） | 同一波人二次触达 |
| D5 | 即刻或掘金发技术贴 | 引来会提建议的人 |

| D7 | 九宫格合集 + 求转发 | 二次传播 |

**D1 是唯一不能省的一天。** 熟人都不点，外面更不会点。

### 15 秒短视频分镜（三段任选其一）

**A · 雨天（最出片）**

- 3–7s 镜头慢慢转，屋檐、雾、水塘

- 快切五种天气，每段 2.5 秒，字幕标天气名

**C · 共创**
- 0–4s 上期留言截图（"夜里太黑"）
- 4–10s 现在的夜景
- 10–15s 面板打开的样子，字幕："下一条想做哪个？"

## 7. 怎么跟访客讲共创规则（避免误会）

一定要说清三句话，否则会有人以为留言等于立刻上线：

1. **留言不是投票，是提案**：我会看，会归类，会挑。
2. **上不上线由我定**：受工作量、性能、和其他功能冲突影响。
3. **你的私人设置只在你手机里**：改色调、视角不会影响别人，也不会自动变成公共内容。

需求清单分四态对外公示：**待评估 / 待开发 / 已上线 / 否决**。

## 8. 看什么数据（以及看不到什么）

- **看不到**：线上总访问量。页面只做本机计数，不上报任何请求——这是刻意的隐私设计。
- **能看**：留言条数（FormSubmit 邮件）、群里被 @ 的次数、有人问"怎么还没加"。
- **判断标准**：如果 D1 发出后 3 天内留言 ≥ 5 条，说明有生命力，可以加码小红书；如果没人留言只有人点赞，说明"共创"没讲明白，改标题。

## 9. 风险与注意

- **别承诺时效**："下周做"只在确定能做时才说。
- **别甩 .html 文件**：微信里收 .html 只当文件，打不开。发链接。
- **隐私模式**：`localStorage` 被禁时访问计数不工作，属正常，不影响玩。
- **声音**：浏览器要求先点一下才出声，宣传时别说"打开就有 BGM"，说"点一下就能听到雨声"。
- **未成年人**：家长群里发时，别引导孩子留真实姓名或个人联系方式。
