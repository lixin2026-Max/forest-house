## 待评估（需要负责人先定方向）

| 构想 | 两套方案 | 耗时 | 性能代价 | 冲突风险 |
|---|---|---|---|---|
| 访客构想真的进入场景 | A. 人工整理成 JSON，静态加载（安全、可控） | 1 天 | 忽略 | 低 |
| | B. 后台审核后写库，页面拉取（需服务器与审核后台） | 4–5 天 | 需网络请求 | 高：破坏"离线可玩/零后端" |
| 访客投票 | A. 本地存储投票，不聚合（只能自娱） | 0.5 天 | 无 | 低 |
| | B. FormSubmit 收集票数，人工汇总 | 0.5 天 | 无 | 中：无实时结果 |
| 快照截图分享 | A. canvas.toDataURL 存本机下载 | 0.5 天 | 瞬时 | 低 |
| | B. 接图床/社交分享 API | 2 天 | 需外链 | 高：与 CSP/无外链原则冲突 |
| 场景物件命名文案投稿 | A. 留言表单加字段，人工审核后写进配置 | 1 天 | 忽略 | 低 |
| | B. 独立投稿页 + 审核后台 | 4 天 | 需后端 | 高 |

## 否决 / 暂不做

| 构想 | 原因 |
|---|---|
| 实时多人同场景 | 需要长连接服务器与状态同步，与"零后端、离线可玩"直接冲突 |
| 访客直接改场景代码 | 安全与稳定性不可控，最终决定权归负责人 |
| 收集访客精确定位 / 设备指纹 | 与隐私设计冲突，访问统计只做本机计数 |
